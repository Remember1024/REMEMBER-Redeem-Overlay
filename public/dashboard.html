OBS Browser Source Setup

  1. In OBS Studio, click + under the Sources dock.
  2. Select Browser and name it (e.g. REMEMBER Redeem Overlay).
  3. Set URL to: http://localhost:3000/overlay.html
  4. Recommended Dimensions: Width 600, Height 250 (or 1920x1080 full canvas).
  5. Check "Shutdown source when not visible" = Unchecked, "Refresh browser when scene becomes active" = Unchecked.
