📖 วิธีนำไปใส่ใน OBS Studio ใน 3 ขั้นตอน:
  1. คลิกปุ่ม Copy URL สีม่วงด้านบนนี้
  2. ในโปรแกรม OBS Studio: ดูที่กล่อง Sources (แหล่งสัญญาณ) กดปุ่ม + แล้วเลือก Browser (เบราว์เซอร์)
  3. วางลิงก์ที่ก๊อปปี้มาลงในช่อง URL (ตั้งขนาด Width: 600, Height: 90) แล้วกด OK จบเลย!
